# Stage Estimates

These are engineering working-day ranges for a focused implementation, excluding long client-side approval delays.

| Stage | Scope | Estimate |
| --- | --- | --- |
| 0 | Audit, transfer, docs, baseline | 1-2 days |
| 1 | Product foundation: repo structure, DB, Redis, API, worker, scheduler, Docker, auth base | 6-10 days |
| 2 | Push MVP: subscriptions, campaigns, queue, retries, SDK, SW, basic admin | 8-14 days |
| 3 | Raschini migration | 2-4 days |
| 4 | YULIAWAVE onboarding | 2-4 days |
| 5 | WordPress plugin | 7-12 days |
| 6 | Bitrix module | 8-14 days |
| 7 | Production hardening: monitoring, backups, load test, security review, on-premise package | 6-10 days |
| 8 | V2 mobile landings | 12-20 days |

## Commercial MVP

The first sellable version should be considered ready after stages 1-4 plus the minimum integration path needed for the second client. If WordPress is the acquisition channel, stage 5 moves before broad commercial launch.
